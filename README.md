# Near-Real-Time-Cloud-Service-Availability-Tracking
Implementing Scheduled Synthetic Monitoring for Near Real-Time Cloud
Service Availability Tracking: A Case Study of Central African Building
Society

This study explores scheduled synthetic monitoring as a proactive approach to tracking cloud service availability, using Central African Building Society (CABS) as a case study. It addresses the limitations of manual monitoring techniques, such as SSH, ping, and grep, by introducing an automated framework that simulates user interactions, detects service disruptions, and generates timely alerts. The study evaluates its reliability and efficiency compared to traditional methods, highlighting its potential to reduce downtime, improve service resilience, strengthen risk management, and support digital transformation in financial institutions.
